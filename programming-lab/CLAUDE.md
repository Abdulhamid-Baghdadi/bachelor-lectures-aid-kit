# Programming Lab

Interactive labs for TU Wien's Programmieren 1 and 2, taught in C in 2015: searching, sorting and heaps, pointers, the stack,
malloc and free, then a comparison of how C, C++, Java, Python and JavaScript give memory back. Layers and rules:
ARCHITECTURE.md. Tests: `node --test "tests/unit/*.test.js"`.
Sources, in `H:\My Drive\02_Personal\02_Education\TU\01_TU_Bachelor\`: the course book Klima and Selberherr (2010),
`Programmieren in C.pdf` (373 pages, text layer works; printed page = PDF page − 7 to − 10, read the page header), and
the slides of Ceric et al. (2015) in `Programmieren 1\Vorlesungen\` and `Programmieren 2\VO\`, which follow the book.
The question catalogues (`Fragenkatalog_*.pdf`) have no worked answers. The comparison lab quotes each language's own
documentation (README.md, Sources); add nothing about a language without quoting a primary source first.
Part of `../PLAN.md`.
